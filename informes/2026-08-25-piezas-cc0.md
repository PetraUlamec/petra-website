## 4. CÓMO METERLOS SIN HUNDIR LA WEB

### 4.1 Presupuesto por sala (objetivo vs hoy)
Hoy: 230-700 mallas por sala ≈ 230-700 draw calls → ~28 FPS en Radeon 610M (el cuello es draw calls/CPU, no triángulos).

| Métrica | Hoy | Objetivo por sala | Por qué |
|---|---|---|---|
| Draw calls | 230-700 | **< 100-150** | iGPU + driver DX12/OpenGL de AMD: coste CPU por llamada alto |
| Triángulos | ? | **< 400-500 k visibles** | 610M ≈ 1-1,5 TFLOPS: sobra para low-poly si las calls bajan |
| Memoria texturas | ? | **≤ 30-40 MB/sala** (KTX2) | RAM compartida con CPU |
| GLB por sala | — | **≤ 8-15 MB total** | carga inicial < 2-3 s en conexión media |

Trucos que dan ese número: `join` de props estáticos por material, `InstancedMesh`/drei `<Instances>` para repetidos (sillas, tazas, plantas), atlas de texturas compartido (KayKit ya trae UN atlas 1024²), frustum culling por sala (monta solo la sala activa).

### 4.2 Pipeline gltf-transform (doc ✅ https://gltf-transform.dev/cli — las antiguas `/cli/usage` y `/cli/commands/*` devuelven 404)
```bash
npm install --global @gltf-transform/cli
gltf-transform inspect entrada.glb                 # audita tris/materiales/texturas
gltf-transform dedup entrada.glb tmp1.glb          # "Deduplicate accessors, textures, materials, meshes"
gltf-transform prune tmp1.glb tmp2.glb             # "Remove unreferenced properties from the file" (nodos vacíos)
gltf-transform join tmp2.glb tmp3.glb              # "Join meshes and reduce draw calls"
gltf-transform simplify tmp3.glb out.glb --ratio 0.5 --error 0.001   # basado en meshoptimizer
```
Compresión de geometría — **meshopt vs draco con three 0.185**: GLTFLoader soporta ambos (doc r185 ✅ threejs.org/docs/pages/GLTFLoader.html): `.setDRACOLoader()` *"Required for decoding assets compressed with the KHR_draco_mesh_compression extension"* y `.setMeshoptDecoder()` *"Required for decoding assets compiled with the EXT_meshopt_compression extension"*. **Recomendación: meshopt** (decodifica mucho más rápido, decoder ES module empaquetado por tu bundler — nada que servir en /public) + brotli/gzip en el hosting; draco solo si necesitas ratio máximo (entonces sirve `node_modules/three/examples/jsm/libs/draco/gltf/*` → `/public/draco/gltf/`).
```bash
gltf-transform meshopt out.glb tienda.glb --level medium
```
Texturas a KTX2/Basis: los comandos `etc1s`/`uastc` requieren **KTX-Software ≥ 4.4.0** instalado (CLI `ktx`; error literal: *"Command \"ktx\" not found. Please install KTX-Software…"*).
```bash
gltf-transform uastc in.glb t1.glb --slots "{normalTexture,occlusionTexture,metallicRoughnessTexture}" --level 4 --rdo --rdo-lambda 4 --zstd 18
gltf-transform etc1s t1.glb final.glb --quality 255
```
**¿Qué transcoder servir?** `examples/jsm/libs/basis/basis_transcoder.js` + `.wasm` (✅ existen en three@0.185) → cópialos a `/public/basis/`:
```bash
mkdir -p public/basis && cp node_modules/three/examples/jsm/libs/basis/basis_transcoder.{js,wasm} public/basis/
```
Registro en R3F (drei, doc ✅ pmndrs.github.io/drei/loaders/gltf-use-gltf):
```tsx
import { useGLTF } from '@react-three/drei'
import { KTX2Loader } from 'three/addons/loaders/KTX2Loader.js'
import { MeshoptDecoder } from 'three/addons/libs/meshopt_decoder.module.js'

const ktx2 = new KTX2Loader().setTranscoderPath('/basis/').detectSupport(gl)
useGLTF('/models/sala.glb', true /*draco*/, true /*meshopt*/, (loader) => {
  loader.setKTX2Loader(ktx2); loader.setMeshoptDecoder(MeshoptDecoder)
})
```
⚠️ drei avisa: `useGLTF(url, true)` usa Draco del CDN de Google (`www.gstatic.com`); para web 100% autocontenida pasa path local `useGLTF(url, '/draco/gltf/')`.

Alternativa **gltfpack** (README ✅ github.com/zeux/meshoptimizer/tree/master/gltf): `-cc` = compresión EXT_meshopt_compression (combinar con gzip/brotli), `-tc` = *"convert all textures to KTX2 with BasisU supercompression"* (lleva Basis integrado pero necesita binario nativo compilado), `-kn` conserva nodos nombrados, `-si R` simplifica, cuantización KHR_mesh_quantization por defecto. Comando oficial del ejemplo three.js r185 `webgl_loader_gltf_compressed`:
```bash
gltfpack -i scene.gltf -o scene.glb -cc -tc
```

### 4.3 gltfjsx → componentes R3F tipados (README ✅ github.com/pmndrs/gltfjsx)
*"turns GLTF assets into declarative and re-usable react-three-fiber JSX components"*

## 5. TRAMPAS

1. **Escala/unidades**: glTF define 1 unidad = 1 metro, pero muchos packs low-poly no respetan metro humano (Kenney/Quaternius antiguos vienen "de juguete"). Normaliza: mide una puerta/silla del pack y fija factor de escala global por biblioteca antes de mezclar.
2. **Origen del pivote**: vosotros apoyáis piezas en el suelo; la mayoría de assets viene **centrado en su bounding box**. Solución estable: envolver cada pieza `<group position-y={offset}>` calculado una vez (o reoriginar en Blender con origen a la base). gltfjsx te da los offsets por nodo; automatízalos en un wrapper.
3. **Y-up vs Z-up**: glTF es Y-up ✅; FBX/OBJ suelen ser Z-up (Blender también). Si importas FBX/OBJ de Quaternius/Kenney y sale "tumbado", es eso. **Evita el problema: usa siempre las variantes glTF/GLB cuando existan** (Quaternius nuevo y KayKit las traen).
4. **Modelos negros sin environment**: materiales PBR metálicos (metalness≈1) necesitan envMap; sin él salen negros. Solución R3F: `<Environment preset?>` NO (descarga externa) → genera tu HDRI local de Poly Haven (CC0) y cárgalo con `<Environment files="/hdri/teahouse_1k.hdr">`, o `Environment` + lightFormers. Con flat-color low-poly basta luz ambiente + direccional, pero las texturas PBR de Poly Haven lucirán mal sin env.
5. **Las licencias cambian**: Poly Pizza redistribuye trabajo de terceros; Kenney puede cerrar packs (ya vende bundles); Sketchfab permite borrar modelos. Protocolo: guarda copia del ZIP + captura/PDF de la página de licencia con fecha, y mantén un `LICENSES.md` del proyecto (asset → autor → licencia → URL → fecha). CC0 no caduca, pero la disponibilidad sí.
6. **Miles de triángulos disfrazados de low-poly** (típico en Sketchfab/Poly Pizza): audita SIEMPRE con `gltf-transform inspect` antes de integrar; rechaza > ~10 k tris por prop pequeño o pásale `simplify --ratio 0.3`.
7. Extra: itch.io "Name your own price" = legal poner $0 (KayKit/Tiny Treats lo dicen explícitamente para la versión FREE); los tiers EXTRA/SOURCE de pago no te dan derechos CC0 adicionales que necesites.
